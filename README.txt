생각이 많아지면 — 움직이는 시각시

생각 쪽에 머물면 생각이, 용기 쪽에 머물면 용기가 화면을 채웁니다.
디자인 스크린샷 11장(첫 화면 50:50, 생각 52·55·65·90·90·100, 용기 70·85·92·100)을 장면으로 삼고,
장면과 장면 사이는 대각선·글자 모양·문구·숫자를 모두 이어서 움직입니다.

파일
- index.html: 화면 구조·스타일·커서
- app.js: 진행(생각 쪽 +, 용기 쪽 −), 장면 사이 보간, 글자 변형, 문구·숫자 배치
- assets/scenes.json: 장면 데이터 (아래 변환기로 생성 — 직접 고치지 마세요)
- assets/glyphs/: 생각·용기 단계별 SVG 원본 (생각0단계는 폰트 글자라 첫 화면 그림에서 딴 트레이스를 사용)
- tools/scenes/: 장면 데이터 변환기
  - canon.py: 단계 SVG를 정리한 조각 (생각 6조각, 용기 7조각). 잘린 ㅇ은 타원으로 복원, 합쳐진 조각은 분리, 테두리는 두께 반영
  - build_scenes.py: 장면별 대각선, 대각선과 글자 사이 여백, 문구 위치, 숫자 위치 (스크린샷에서 측정한 값)
  - place.py, *.json: 스크린샷에서 측정한 글자 위치·대각선
  - 변형 방식: 직선 획은 모서리끼리 짝지어 꼭짓점만 이동(사이 모양도 항상 직선), ㅇ은 항상 타원
- assets/: 폰트(Pear, Neurimbo)와 예전 이미지 자료

다시 만들기 (SVG나 측정값을 바꿨을 때)
  python3 tools/scenes/build_scenes.py     (numpy, opencv-python 필요)

좌표: 대지 1920×1077. 문구는 Pear, 숫자는 Neurimbo.

실행
1. 터미널에서 index.html이 있는 폴더로 이동합니다.
2. python3 -m http.server 8000 을 실행합니다.
3. 브라우저에서 http://localhost:8000 을 엽니다.
index.html을 더블클릭하면 브라우저 보안 정책 때문에 장면 데이터가 로드되지 않을 수 있습니다.

조작
클릭으로 시작. 생각(검정) 쪽에 머물면 생각이, 용기(흰색) 쪽에 머물면 용기가 커집니다.
R 또는 ↺로 처음으로.
